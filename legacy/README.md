# Legacy — early web prototype (archived)

This folder contains an **early, abandoned prototype** of GoalSight built as a
**React + Vite frontend** and a **Node.js / Express + MongoDB backend** (a
365Scores-style stats website). It is **not** part of the final product.

The shipped GoalSight system is the **Flutter app + FastAPI analysis service + AI
computer-vision model + Supabase backend** — see the [project README](../README.md)
and [docs/](../docs/) for everything current.

These files are kept only for historical reference and are not maintained.

| Item | What it was |
|---|---|
| `frontend/` | React 18 + Vite + TailwindCSS web client |
| `backend/` | Express + MongoDB + Socket.IO API |
| `CHECKLIST.md`, `DESIGN_SYSTEM.md`, `HOME_PAGE_IMPLEMENTATION.md`, `LIVE_SCORES_*.md`, `QUICK_START.md`, `SETUP.md` | Docs for the old web prototype |
